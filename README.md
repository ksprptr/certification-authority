# Certification Authority

Certification authority that allows you to generate certificates and sign files. You can also store the certificates and the signed files in the archive.

## Dependencies

[ASP.NET Core](https://dotnet.microsoft.com/en-us/apps/aspnet) version `7 or later..`

[ASP.NET SDK](https://dotnet.microsoft.com/en-us/download) version `7 or later..`

## Installation

Open the project folder in Visual Studio or JetBrains Rider

Wait for the project to load and the initialization of NuGet packages

Start the dev server using the start button marked as the green arrow

Open [localhost:5000](http://localhost:5000) in your browser to see the project home page.
